# Villafarma Backend - Esqueleto (Spring Boot + JWT)

Sigue las instrucciones en el README del proyecto para importar en NetBeans, configurar DB y ejecutar.

Resumen rápido:
- Reemplaza credenciales en `src/main/resources/application.properties`.
- Inserta roles iniciales (ROLE_USER, ROLE_ADMIN) en la BD antes de registrar usuarios.
- Abrir como proyecto Maven en NetBeans (File -> Open Project..., seleccionar carpeta con pom.xml).
- Ejecutar el proyecto con Run -> Run Project.
